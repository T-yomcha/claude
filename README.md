# Эмулятор стекового процессора (вариант 12)

Учебный эмулятор процессора с графическим интерфейсом на Python (tkinter):
безадресная система команд, гарвардская архитектура.
Задача 1 — поиск максимума в массиве, задача 2 — свёртка двух массивов (6 элементов, числа без знака).

Быстрый запуск:
```bash
cd emulator
python main.py
```

Подробная инструкция, описание архитектуры и системы команд — в [emulator/README.md](emulator/README.md).
